# 中央版規則對照

法源：都市更新建築容積獎勵辦法（民國114年1月13日修正，台內國字第1130815906號令）、都市更新條例第65條（民國113年11月13日修正公布）。

符號：B＝更新單元基準容積＝土地面積 × 法定容積率（辦法 §3）；O＝原建築容積。下表百分比除另註明外皆以 B 計。

## 時程獎勵（§14）

辦法於 108.05.15 修正發布，§14 自「修正條文施行日起」計算：

| 期間 | 劃定應實施更新之地區 | 未經劃定 |
| --- | --- | --- |
| 第一期 108.05.15–113.05.15 | 10% | 7% |
| 第二期 113.05.16–118.05.15 | 5% | 3.5% |
| 118.05.16 以後 | 0 | 0 |

起訖日依臺北市都市更新處公告的「108年5月15日起至113年5月15日止」寫法。辦法 §21 為自發布日施行，依中央法規標準法 §13 應自發布日起算第三日生效，起訖日在實務上可能有 1–2 日差異，因此報核日落在期限前後 3 日內時程式會提示向主管機關確認。

## 總上限（條例 §65）

| 模式 | 上限（獎勵後總容積） | 條次 |
| --- | --- | --- |
| 一般 | 1.5B，且不超過都市計畫法施行細則規定 | §65-1 |
| 原容積高於基準容積 | max(0.3B＋O, 1.2O)，程式另取不低於 1.5B | §65-2-1 |
| 高氯離子／耐震不足 | 1.3O，且不得再申請辦法、自治法規及其他獎勵 | §65-2-2、§65-3 |
| 策略性更新地區 ≥ 1 萬㎡ | max(2B, 0.5B＋O)，須依 §12-1 方式實施 | §65-2-3 |

地方自治法規另訂獎勵上限為 0.2B（策略性更新地區 0.4B），屬 §65 第6項，於臺北市版處理。
