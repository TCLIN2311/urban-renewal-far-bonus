# 都更容積獎勵檢核表

都市更新容積獎勵的勾選式試算工具。頁面上方可切換「中央（各縣市通用）」或「臺北市」，勾選各條獎勵後即時統計獎勵 %、獎勵面積與核計後允建容積。

直接用瀏覽器開啟 `index.html` 即可使用；網址加上 `#taipei` 會直接以臺北市模式開啟。`artifact.html` 是發布到 claude.ai Artifact 的版本。

## 輸出

| 輸出 | 用途 |
| --- | --- |
| A4 說明頁（.html） | 給業主的一頁評估表，瀏覽器開啟後列印另存 PDF |
| 簡報用圖片（.png） | 同一張 A4，直接貼進案件簡報 |
| 面積檢討表（.csv） | 逐條 △F 與面積，Excel 可開，供後續面積檢討 |
| 案件檔（.json） | 完整保存勾選狀態，可用「開啟案件檔」還原繼續編修 |

## 案件檔格式

JSON 的 `schema` 為 `urban-renewal-far-bonus/v1`：

- `jurisdiction`：`central` 或 `taipei`
- `law`：法規名稱與版本；`law.local` 為地方法規版本。開啟舊檔時若版本不同會提示
- `project`：土地面積、容積率、基準容積、原建築容積、更新地區、報核日、公告現值、上限模式
- `items[]`：中央各條 `id`、`article`、`title`、`applied`、`choice`、`pct`（基準容積 %）、`area_m2`
- `localItems[]`、`localSummary`：臺北市各項與自治獎勵核計（原始合計、上限、核計、是否扣減）
- `summary`：獎勵合計、上限依據、是否超限、允建容積（㎡、坪）、§18 保證金試算
- `state`：還原畫面用的原始輸入

## 限制

- 屬初步評估，實際額度以主管機關審議核定為準。
- 未納入：容積移轉、依其他法令申請之獎勵（辦法 §4，重複者應扣除）、都市計畫另訂之獎勵。
- 都市更新條例 2026 年修正草案（自主都更一次給滿 1.5 倍、捐贈社宅上限 2 倍）尚未完成立法，未納入。
